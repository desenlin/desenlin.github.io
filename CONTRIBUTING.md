# Contributing

Thank you for helping improve this academic website.

## Appropriate contributions

GitHub Issues are suitable for reporting broken links, typographical errors,
incorrect metadata, accessibility problems, or reproducible website defects.
For questions about research, teaching, student matters, or professional
correspondence, please use the contact information on
[desenlin.com](https://desenlin.com) instead of opening an issue.

## Proposing a change

1. Search existing issues and pull requests to avoid duplication.
2. For a small correction, open a site-correction issue with the page URL and
   the proposed change.
3. For a code or content change, create a focused pull request and explain what
   changed and how it was checked.
4. Do not add copyrighted, confidential, student, or personally identifiable
   information without documented permission.

Opening an issue or pull request proposes a change; it does not modify the live
website. Publication requires review and approval by the repository owner or an
authorized collaborator.
